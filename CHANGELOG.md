# Changelog

## 1.0.1
### Changed
- The original mod file is now downloaded automatically on first start (needs ArchaicLib 1.42.0+): sources and mirrors are listed in `config/archaiclib/originals/` and can be edited there. If the download fails, a banner on the main menu links to the manual download.

## 1.0.0
- First release of the 1.12.2 (Cleanroom) port of The Ultimate Pun Mod 1.5.1 by Gibby008. Requires ArchaicLib 1.40.1+.
- Changes from the original: the Clawset keeps its items (stored per player) instead of losing them on quit; the Sandy/Squid Bomb/Ice Orb/Black Hole projectiles render at their real position; dungeon chests use the vanilla loot tables of the original categories.
