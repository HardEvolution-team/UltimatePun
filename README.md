# The Ultimate Pun Mod Port

Unofficial Minecraft 1.12.2 (Cleanroom) port of **The Ultimate Pun Mod** 1.5.1 (1.7.10) by Gibby008.

- Original: https://www.9minecraft.net/the-ultimate-pun-mod/
- Requires [ArchaicLib](https://www.curseforge.com/minecraft/mc-mods/archaiclib) 1.40.1+

This port contains **no original assets**. Put your own copy of the original jar (`The-Ultimate-Pun-Mod-1.7.10.jar`) into `.minecraft/archaic_originals/`; ArchaicLib reads textures from it at runtime.
